# 🏆 FreeFire Tournament Platform

منصة بطولات فري فاير المتكاملة

## 🎮 المميزات
- عرض البطولات القادمة
- نظام تسجيل للاعبين
- جدول البطولة (Bracket)
- عدّاد تنازلي
- لوحة تحكم للأدمن
- بوت تليجرام للإشعارات
- نظام تصنيف ونقاط
- دردشة مباشرة

## 🛠️ التقنيات المستخدمة
- React + Tailwind CSS
- Supabase
- Node.js (Telegram Bot)

## 🚀 التشغيل
```bash
npm install
npm run dev
